# Offline Field Issue Tracker

A full-stack offline-first application that enables field workers
to report infrastructure issues, even without internet connectivity.

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: SQLite
- Offline Storage: IndexedDB
- Testing: Vitest + Supertest

## Core Features

- Create and manage infrastructure reports.
- Save reports locally while offline.
- Automatically synchronize reports when online.
- Prevent duplicate reports during synchronization.
- Track report status and activity history.
